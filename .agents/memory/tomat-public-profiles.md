---
name: TOMAT public profiles
description: Rules for viewing other users' public profiles from communication screens.
---

Users can view only limited profile fields—name, photo, role, class, and bio—of users in their permitted class circle. Server-side access checks protect the profile endpoint; contact/forum UI actions are only entry points.

**Why:** profile data should support classroom communication without exposing account credentials or unrelated users across classes.

**How to apply:** keep email, WhatsApp, passwords, and other account fields out of public profile responses; reuse exact class relationship checks for students, gurus, and forum participants.
