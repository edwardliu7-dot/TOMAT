Task: PWA Fullscreen & Mobile Game Experience

Saat ini TOMAT diakses via mobile browser dan masih menampilkan status bar (jam, sinyal, baterai) dan navigation bar (tombol Back/Home/Recent) milik Android. Tujuannya membuat tampilan semirip mungkin dengan native game.

Yang perlu dilakukan:

Web App Manifest (public/manifest.json)

Set "display": "fullscreen" (atau "standalone" jika fullscreen terlalu agresif di iOS)
Tambah "orientation": "portrait", "theme_color", "background_color": "#071321"
Pastikan "icons" sudah ada dengan ukuran 192×192 dan 512×512 (maskable)
Meta tags di index.html

<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover"> — untuk support notch/safe-area iPhone
<meta name="mobile-web-app-capable" content="yes"> — Android Chrome fullscreen saat di-Add to Home Screen
<meta name="apple-mobile-web-app-capable" content="yes"> — iOS Safari
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent"> — status bar iOS transparan
<meta name="theme-color" content="#071321"> — warna status bar Android
CSS safe-area insets di src/index.css atau global style:

body { padding: env(safe-area-inset-top) env(safe-area-inset-right) env(safe-area-inset-bottom) env(safe-area-inset-left); }

Pastikan fixed header (home-topbar, appshell-bottom-nav) menggunakan padding-top/bottom yang memperhitungkan env(safe-area-inset-*).

Fullscreen API (opsional, untuk tombol manual) Di splash screen atau saat pertama buka, tawarkan document.documentElement.requestFullscreen() — ini bisa menyembunyikan navigation bar di Android Chrome meski belum di-install sebagai PWA.

Catatan penting:

Status bar & nav bar baru benar-benar hilang secara permanen jika user Add to Home Screen (install sebagai PWA). Tanpa install, browser selalu menampilkan minimal minimal UI.
"Game mode recognition" (seperti Mobile Legends) adalah fitur native Android GameMode API — hanya bisa diakses oleh native APK, tidak bisa dari web app/PWA. Jika menginginkan ini, perlu dibungkus dengan Capacitor.js atau PWABuilder agar menghasilkan .apk yang bisa di-publish ke Play Store.
Untuk solusi paling mendekati native: pertimbangkan wrap PWA dengan Capacitor (menambah @capacitor/core, @capacitor/android) yang bisa menghasilkan APK dari codebase yang ada tanpa rewrite besar.
