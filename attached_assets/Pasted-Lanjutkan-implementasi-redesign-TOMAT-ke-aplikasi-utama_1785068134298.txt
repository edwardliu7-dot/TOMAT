Lanjutkan implementasi redesign TOMAT ke aplikasi utama secara serial, satu layar sampai selesai dan terverifikasi sebelum lanjut ke layar berikutnya.

Konteks proyek:
- Aplikasi utama TOMAT sudah menggunakan React + Vite.
- Jangan membuat aplikasi baru.
- Pertahankan seluruh data, API, autentikasi, navigasi, scoring, task mode, survival mode, leaderboard, koin, EXP, pet, chat, dan fitur guru yang sudah ada.
- Semua teks UI tetap menggunakan bahasa Indonesia.
- Gunakan desain dari mockup di:
  artifacts/mockup-sandbox/src/components/mockups/tomat-redesign/
- Jangan hanya menyalin tampilan mockup. Semua tombol dan navigasi harus tetap berfungsi dengan data asli aplikasi.

Pekerjaan yang sudah selesai:
1. Login siswa/guru:
   - src/screens/LoginScreen.jsx
   - Sudah menggunakan AuthContext dan API login asli.
2. Dashboard siswa:
   - src/screens/HomeScreen.jsx
   - Sudah memakai data akun, koin, EXP, tugas, nilai, zona, pet, dan navigasi asli.
3. Dashboard guru:
   - src/screens/GuruDashboardScreen.jsx
   - Beranda guru sudah mengikuti desain HomeGuruWeb/HomeGuruMobile.
   - Semua tab guru dan API operasional harus tetap berfungsi.
4. Shell visual permainan:
   - GameDesktopWrapper.jsx dan komponen bersama sudah mulai mengikuti desain GameWeb/GameMobile.
   - Pastikan build dan runtime tetap bersih sebelum melanjutkan.

Aturan implementasi:
- Kerjakan hanya satu layar dalam satu waktu.
- Sebelum mengedit, baca file implementasi dan mockup layar tersebut.
- Cari route dan props yang sudah tersedia di src/App.jsx.
- Pertahankan struktur komponen dan pola inline style yang sudah dipakai proyek.
- Jangan menambahkan dependency baru kecuali benar-benar diperlukan.
- Jangan mengubah database atau endpoint tanpa alasan kuat.
- Jangan mengganti data asli dengan mock data.
- Jangan menghapus fitur yang tidak terlihat di mockup.
- Gunakan responsive behavior untuk desktop dan mobile.
- Pastikan tombol yang terlihat sebagai tombol benar-benar memiliki aksi.
- Pastikan tombol navigasi mengarah ke route/tab yang benar.

Verifikasi wajib setelah setiap layar:
1. Jalankan:
   npm run build
2. Periksa:
   git diff --check
3. Restart workflow:
   TOMAT Web App
4. Baca workflow log dan browser console terbaru.
5. Ambil screenshot desktop.
6. Ambil screenshot mobile jika layar memiliki desain mobile.
7. Pastikan tidak ada error JSX, runtime error, provider error, atau request API yang rusak.
8. Setelah satu layar bersih, baru lanjut ke layar berikutnya.

Jika menemukan error:
- Perbaiki error tersebut sebelum lanjut.
- Jangan meninggalkan build dalam keadaan gagal.
- Jangan melanjutkan ke layar lain jika layar aktif belum tervalidasi.

Mulai dari verifikasi akhir layar permainan, lalu lanjutkan secara berurutan ke Leaderboard, Profil, Toko, Komunikasi, dan Nilai/Tugas.
